# Markdown Preview & Compiler

以 Markdown 文件为中心的 VS Code 编辑扩展。提供原生源码编辑、只读分屏预览、独立预览编辑、PDF 预览与导出。

## 安装

从仓库的 [Releases](https://github.com/serendipitylin0731/markdown_preview-compiler/releases) 下载 `markdown-preview-compiler-*.vsix`，在 VS Code 中运行 **Extensions: Install from VSIX...**。本地构建可运行：

```bash
npm ci
npm run package
```

生成的 VSIX 统一放在 `packages/` 目录。扩展运行时不需要网络，渲染库和 PDF 引擎均随安装包提供。

## 使用

打开 `.md` 文件后，点击编辑器标题栏的 Markdown 小图标，即可在左侧编辑源码、右侧实时预览。预览页顶部可切换到分屏、预览编辑或 PDF 预览。排版设置和导出 PDF 仅在 PDF 预览界面显示。

仓库中的 [演示文档](examples/demo.md) 可直接用于体验完整流程。

以下功能也可从 VS Code 命令面板运行：

| 命令 | 效果 |
| --- | --- |
| `Markdown Compiler: 打开上次使用的模式` | 按上次选择的工作模式打开当前文件 |
| `Markdown Compiler: 源码编辑` | 返回 VS Code 原生 Markdown 编辑器 |
| `Markdown Compiler: 分屏预览` | 左侧源码，右侧只读预览 |
| `Markdown Compiler: 预览编辑` | 直接编辑渲染后的段落、标题、列表和表格 |
| `Markdown Compiler: PDF 预览` | 边编辑边查看实际生成的 PDF |
| `Markdown Compiler: 导出 PDF` | 预览并选择 PDF 保存位置 |

扩展不注册模式切换快捷键，以免和其他扩展或用户设置冲突。预览编辑模式内可用 `Ctrl/Cmd+B`、`Ctrl/Cmd+I`、`Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z` 和 Tab / Shift+Tab 编辑内容；`Ctrl/Cmd+S` 会先同步当前编辑，再保存原 Markdown 文件。

可在预览编辑工具栏插入链接、图片、表格、行内或独立代码、行内或独立公式、Mermaid 图表和手动分页符。独立代码和公式可在文档内直接编辑；图表及 HTML 区块提供源码编辑入口。单击链接可放置光标，双击编辑链接，`Ctrl/Cmd+单击` 打开链接。编辑以块为单位写回 VS Code 的 `TextDocument`；预览编辑中的撤销与重做可回退工具栏操作，文件仍由 VS Code 保存。

Markdown 图片的相对路径以当前文件所在目录为基准；HTTP(S) 图片也可用于 PDF 预览和导出。单张图片上限 20 MB。图片文件更新后，点击“更新 PDF”可重新读取。

PDF 排版设置按文件分别保存在本机。再次打开同一文件的 PDF 预览时恢复上次设置；不同文件互不影响。在同一个预览窗口切换模式时也保留本次调整。

排版设置从模板选择开始，可设置纸张、方向、边距、字体、字号、行距、首行缩进、标题、页眉、页脚、封面和目录。内置模板包含上海交通大学红色、蓝色两款，均有对应的正文与封面样式；校标组合遵循[上海交通大学视觉形象识别系统](https://vi.sjtu.edu.cn/index.php/articles/bulletin/13)，使用从 [SJTUTeX 的矢量标识 PDF](https://ctan.org/pkg/sjtutex) 提取的路径。底部图形保留用户确认的 PNG 原图像素并沿用原图横线的线宽。交大模板按 A4、A5、Letter 的横版和竖版预先合成为 300 dpi PNG 背景，PDF 预览和导出直接使用对应图片。选择模板后在文档预览中框选文字，可将该模板应用到选中的段落范围。封面支持副标题、作者、日期开关，日期默认显示当天且可修改；四项文字可直接在封面预览上拖动或用方向键微调。默认页边距为上/下 24 mm、左/右 22 mm；在显示当前模板的页面上点击左上角，右下角会自动对称，继续拖动可调整，也可在四个数字框中精确输入。靠近对称位置时会自动吸附。底边距至少 18 mm，页码固定在右下角，与正文分开；横版预览按纸张尺寸显示模板和页码。PDF 默认让英文沿用当前 VS Code `editor.fontFamily`，中文统一使用宋体字体栈，避免等宽字体回退导致中文字符位置不齐。排版设置中可导入 TTF、OTF、WOFF 或 WOFF2 字体，分别用于正文和标题；手动选中的 PDF 字体优先使用。导入的字体保存在本机扩展数据目录，单个文件上限 20 MB。打印配色采用白底深字、浅色代码块，不受 VS Code 深色主题影响。其他内置正文模板为 `assets/templates` 中的 SVG 图片。模板只影响 PDF，不改动 Markdown 正文。

### 导入图片模板规范

点击“导入图片模板”会打开单独的配置界面。填写模板名称后，可为 A4、A5、Letter 各自的纵向和横向分别上传内页与封面。支持 PNG、JPEG、WebP、SVG，单张上限 20 MB；图片应采用目标纸张的长宽比，建议至少 150 dpi，并在中部留出正文空间。至少上传一张内页才能保存模板；封面只能为已有内页的同规格组合添加。未上传封面的组合在勾选封面页时使用内页图片；未上传内页的纸张或方向在排版设置中不可选。导入后可从模板列表导出当前规格的内页原图。

## 支持的语法

CommonMark、GFM 表格与任务列表、脚注、标题锚点、行内和块级 KaTeX 公式、代码高亮、Mermaid 图表、`==高亮文字==`，以及经过清理的常用 HTML。分屏预览中的任务框可以直接勾选，修改会写回对应的 Markdown 标记。文件开头的 `---` 元数据区不显示正文；其中以 `tag:` 开头的行按英文逗号分成多个顶部标签，PDF 中可用“显示标签”开关控制。`<details><summary>标题</summary>内容</details>` 和 `:::info[标题]`、`:::warning[标题]` 等块可包含 Markdown 列表及代码块；分屏预览中可展开，编辑文件时保持原有展开状态，PDF 中全部展开。HTML 区块可在预览编辑模式中通过“编辑源码”修改。相对路径图片按当前 Markdown 文件目录解析；在线图片会使用系统或 VS Code 配置的代理，并在加载失败时自动重试。最终仍无法加载的图片和图表会显示错误提示。

## 当前限制

- PDF 页面以图像方式写入。超链接仍可点击，但导出 PDF 中的正文不可搜索或选择。
- 很长的段落会按渲染后的行跨页续排；长表格按行拆分，长代码块按行拆分。特别高的单张图片或单个表格行仍可能超出页面可用高度。
- 不受支持的 Markdown 扩展和复杂 HTML 请在源码模式编辑。编辑一个可视化块时会规范化该块的 Markdown 写法；其他块保持原样。
- 自定义模板图片作为页面背景使用，应在中部留出正文空间。导入大小上限为 20 MB。

## 开发和验证

```bash
npm ci
npx playwright install chromium
npm run check
npm test
npm run render:sjtu
npm run package
```

测试会在 Chromium 中检查块级写回、表格编辑、公式与图表、脚注、自动与手动分页，以及实际 PDF 字节。扩展入口使用 VS Code API，Webview 使用严格 CSP 和 DOM 清理。Windows、macOS 和 Linux 均使用相同的 JavaScript 实现；构建工作流分别在三个平台运行。完整的 VS Code 图形界面操作仍需在目标平台人工验收。
